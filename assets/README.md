# `assets/` — images and sound

Everything the game loads from disk at runtime. Nothing here is code, and
nothing here is generated by the build.

The path to this folder is baked into the binary at build time (CMake defines
`KFC_GRAPHICS_ASSETS_DIR`), so the game finds these files no matter which
directory it is launched from.

```
assets/
├── pieces/    piece sprites, board and background images
└── sounds/    sound effects
```

---

## `pieces/`

One folder per piece, named `<colour><kind>` — `w` or `b`, then the piece
letter:

| Folder | Piece | | Folder | Piece |
|--------|-------|-|--------|-------|
| `wK` / `bK` | King   | | `wB` / `bB` | Bishop |
| `wQ` / `bQ` | Queen  | | `wN` / `bN` | Knight |
| `wR` / `bR` | Rook   | | `wP` / `bP` | Pawn   |

Each piece folder holds a `states/` folder with one subfolder per state
(`idle`, `move`, `jump`, `long_rest`, `short_rest`). A state is a numbered
sequence of PNG frames plus a `config.json` describing how to play them.

Two images sit alongside the piece folders:

| File | Used for |
|------|----------|
| `board.png` | The playing board, including its decorative frame. The grid is cropped out of it at a fixed inset — see `BoardLayout`. |
| `background.png` | The scene behind the board. Scaled to cover the window at whatever size it currently is. |

Sprites are **transparent PNGs** — the alpha channel is what lets a piece blend
onto the board instead of being pasted as a rectangle.

## `sounds/`

Drop a WAV file with one of these exact names here and the game plays it. No
rebuild is needed; until a file exists, that cue is simply silent.

| File | Plays when |
|------|-----------|
| `move.wav` | A piece finished an ordinary move |
| `capture.wav` | A move captured an enemy piece |
| `start.wav` | The game began |
| `end.wav` | The game was decided (win or draw) |

Keep them short — a fraction of a second. They play asynchronously on every
matching event, so long clips would overlap.

Filename case does not matter on Windows (`end.WAV` works), but **it does on
Linux and macOS** — use lowercase names there.

These four are the whole set. There is no cue for an illegal move, for a
disconnect countdown, or for each colour moving separately; adding one means
adding a value to `kfc::audio::Sound` and a case in the sound player.

`sounds/moresound/` holds spare clips that are **not** wired to anything. It is
excluded from version control.

---

## How these are wired up

The event → cue mapping lives in `kfc::audio::SoundBoard` (in
[`logic/`](../logic/README.md), so it is testable without an audio device).
Which file a cue plays, and whether it makes any noise at all, is the sound
player's business — see [`ui/README.md`](../ui/README.md).

Sprite loading and animation live in `ui/animation/`.
